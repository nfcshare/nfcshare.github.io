Publicar no GitHub um clique, sem copiar e colar

Repositório deste cartão: . Se ainda não existir, ele é criado na hora de publicar.

Ainda não tenho a chave
  1. Abra github.com → criar chave (Fine-grained token).
  2. Token name: cartões. Expiration: 1 ano.
  3. Resource owner: nfcshare.
  4. Repository access: All repositories (para criar cartões novos) ou só o repositório da pessoa (para ela editar o próprio).
  5. Permissions → Repository: Contents = Read and write · Administration = Read and write · Pages = Read and write.
  6. Generate token, copie e cole aqui. Se pedir aprovação, aprove em github.com/nfcshare → Settings → Personal access tokens.

A chave fica guardada só neste navegador.
